# 🏦 Sistema de Atención al Cliente Automatizado

Sistema inteligente de atención al cliente para Banco Henry usando LangChain y GROQ.

## 🚀 Inicio Rápido

### 1. Instalar dependencias
```bash
pip install -r solution/requirements.txt
```

### 2. Ejecutar interfaz web
```bash
streamlit run app.py
```

### 3. Ejecutar pruebas
```bash
python tests/run_tests.py
```

## 📝 Funcionalidades

- ✅ **Consulta de balances** por cédula
- ✅ **Información bancaria** (cuentas, tarjetas, transferencias)  
- ✅ **Respuestas generales** con IA
- ✅ **Interfaz web interactiva**
- ✅ **Pruebas automatizadas**

## 📚 Documentación Completa

Ver [`documentacion_proyecto.md`](documentacion_proyecto.md) para detalles técnicos completos.

## 🛠️ Tecnologías

- **LangChain** + **GROQ** (Llama3-70B)
- **FAISS** + **Sentence Transformers**
- **Streamlit** + **Pandas**
- **Unittest** para testing
